# Financial Asset Performance Analysis

## Overview

This project calculates the absolute and percentage price change of a financial asset using Python.

## Objectives

- Identify the initial and final asset prices.
- Calculate the absolute price change.
- Calculate the percentage price change.
- Display the results in a readable format.

## Technologies

- Python 3

## Methodology

The absolute price change is calculated as:

Price Change = Final Price - Initial Price

The percentage price change is calculated as:

Percentage Change = (Price Change / Initial Price) × 100

## Example Results

| Metric | Value |
|---|---:|
| Initial Price | 100 |
| Final Price | 108 |
| Price Change | 8 |
| Percentage Change | 8% |

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run `main.py`.

## Limitations

This example uses manually entered prices. It does not include transaction costs, dividends, taxes, or risk-adjusted performance metrics.
